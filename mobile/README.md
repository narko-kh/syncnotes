# SyncNotes — Mobile

اپ موبایل وظایف و یادداشت‌ها با همگام‌سازی لحظه‌ای و حالت آفلاین.
**React Native (Expo) · TypeScript · Expo Router · Zustand · i18next · Socket.IO**

## راه‌اندازی

```bash
cp .env.example .env     # آدرس سرور رو تنظیم کن
npm install
npx expo start           # بعد با Expo Go یا شبیه‌ساز باز کن
```

آدرس سرور (`EXPO_PUBLIC_API_URL`):
- شبیه‌ساز اندروید: `http://10.0.2.2:3000`
- گوشی واقعی (همون Wi-Fi): `http://<IP-کامپیوتر>:3000`
- در محیط واقعی حتماً `https` استفاده کن.

## قابلیت‌ها

- ثبت‌نام و ورود؛ نشست تو Keychain/Keystore (`expo-secure-store`) ذخیره میشه
- وظایف و یادداشت‌ها با برچسب، جستجو و فیلتر (روی نسخه‌ی محلی، پس فوری و آفلاین)
- **همگام‌سازی لحظه‌ای** بین دستگاه‌ها با WebSocket
- **حالت آفلاین (اول محلی)**: تغییرات فوراً اعمال میشن و تو صف ارسال می‌مونن تا اینترنت برگرده
- دو زبانه (فارسی RTL / English) با i18next، تم روشن/تاریک/سیستم
- نشانگر وضعیت همگام‌سازی (زنده، آفلاین، در حال همگام‌سازی، N مورد در انتظار)

## معماری

```
app/                 صفحه‌ها (Expo Router)
  (auth)/            ورود و ثبت‌نام
  (app)/             لیست، ویرایشگر، تنظیمات
src/
  domain/            تایپ‌های اصلی
  services/
    api/             کلاینت HTTP (تمدید خودکار توکن) و درخواست‌ها
    realtime/        WebSocket
    sync/            موتور همگام‌سازی
    storage/         ذخیره‌ی امن نشست
  stores/            Zustand: auth، items (+صف آفلاین)، settings، sync
  components/        کامپوننت‌های UI
  i18n/              ترجمه‌ها و جهت متن
  theme/             رنگ‌ها و تایپوگرافی
```

## همگام‌سازی چطور کار می‌کنه

1. هر تغییر روی نسخه‌ی محلی اعمال میشه و تو **outbox** میره (با UUID که خود اپ می‌سازه).
2. موتور sync صف رو به ترتیب می‌فرسته؛ تغییرات پشت‌سرهم یک آیتم ادغام میشن.
3. بعد از ارسال، تغییرات جدید سرور با `updatedSince` گرفته میشه (شامل حذف‌ها).
4. WebSocket تغییرات بقیه‌ی دستگاه‌ها رو لحظه‌ای میاره.
5. تعارض: اگه تغییر ارسال‌نشده‌ی محلی داری، نسخه‌ی محلی برنده‌ست (آخرین تغییر برنده).

## نکته‌ی RTL

بعد از عوض کردن زبان به/از فارسی، متن‌ها فوراً عوض میشن ولی **جهت صفحه** بعد از راه‌اندازی دوباره‌ی اپ اعمال میشه (محدودیت React Native). اپ پیشنهاد ری‌استارت میده.
